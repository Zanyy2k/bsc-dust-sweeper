# BSC Dust Sweeper

A DustSweeper-style protocol on BNB Smart Chain. Users approve dust tokens once; the bot automatically swaps them to BNB and returns the proceeds.

## Structure

```
contracts/   Solidity smart contract
bot/         Python keeper bot
frontend/    React user interface
```

## Setup

```bash
cp .env.example .env
# fill in your values
```
